# Airwaylink Banner Studio

**Airwaylink Banner Studio** (v0.08) is a specialized standalone web application for generating high-resolution (5664×2500) virtual airline focus airport banners.

## Features
- Procedural atmospheric backdrops (daylight snowy mountains, deep night runway, Denver mountain strata).
- Offline 17,000+ airport database with ICAO auto-complete and edge-proximity downscaling.
- Strict binary search JPEG compressor ensuring < 2,000,000 Bytes output.
- Responsive canvas scaling with window auto-fit and percentage scale presets.
- Persistent custom logo storage with IndexedDB.
- Clean branding with modern avionics typography.
